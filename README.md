## 📋 Overview

This repository contains all programming assignments and demonstrations for **CSE210** (C# Programming) at BYU-Idaho / BYU-Pathway.

Each week focuses on core C# and Object-Oriented Programming concepts through practical console applications.

---

## 📂 Project Structure (by Week)

- **Week 01** — Basic C# programs (input/output, math, conditionals)
- **Week 02** — Journal Program & Resume Builder
- **Week 03** — Fraction class & Scripture Memorizer
- **Week 04** — Online Ordering & YouTube Video classes
- **Week 05** — Homework tracking (inheritance) & Mindfulness activities
- **Week 06** — Eternal Quest goal tracking system + Shapes hierarchy
- **Week 07** — Exercise Tracking (polymorphism)

---

## ✨ Key Concepts Demonstrated

- Classes & Objects
- Inheritance & Polymorphism
- Encapsulation
- Abstraction
- Collections (Lists, Dictionaries)
- File I/O
- User input & console interaction
- Clean code organization

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/HighPriest19/cse210-projects.git
   cd cse210-projects
   ```

2. Navigate to any project folder (e.g., `week02/journal`).

3. Run with .NET:
   ```bash
   dotnet run
   ```

   Or open the `.sln` files in Visual Studio / VS Code.
